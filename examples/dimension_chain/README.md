# 尺寸链教学示例

这个示例展示完整 GT 内容和尺寸记录如何对应，不是六个真实 CAD 案例的标定结果，也不是能直接运行的完整制图任务。输入 STEP、投影图和 CAD 工具附着记录不在本示例中。

为集中说明搜索，假设特征匹配、视图关联和标注有效性已经确认。实体 ID 在两份 JSON 中共用便于阅读；正式评测需要由匹配器建立对应，不能向模型提供隐藏 GT 标签。

- [gt.json](gt.json)：需要确定宽度 50、高度 40、孔心 X=20、Y=15 和直径 10，并表达通孔条件。示例范围限于这五个连续量和一个离散条件；未评价完整三维零件的厚度等参数。
- [prediction.json](prediction.json)：改用右边和上边标注孔位置，包含视图引用和结构声明。
- [expected.json](expected.json)：人工推导的预期结果与删改实验，不是程序运行报告。

X 图：`left.x=0 → right.x=50 → hole_1.center.x=20`。

Y 图：`bottom.y=0 → top.y=40 → hole_1.center.y=15`。

直径由单独的标量尺寸确定；通孔由结构标注表达。已连接的 X 图不能补足缺失的 Y 信息。

这里没有参考二维工程图，GT 也不规定模型必须选择哪一条尺寸链。
