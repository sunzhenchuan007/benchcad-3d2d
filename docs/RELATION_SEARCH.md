# 尺寸关系链验证算法

原讨论的实现路线是：按轴拆图，将标注转为有方向的差值关系，从固定基准传播；静态检查可用 BFS／DFS，增量查询可用带权并查集。先实现这一类确定的线性关系，再扩展一般约束。

## 1 从标注到边

图的节点是单个几何量，如 `hole_1.center.x`，而不是混合全部坐标的“孔”。每条有效轴向尺寸转换成：

```text
q[to] - q[from] = delta
```

加入两条邻接边：`from → to` 权重 `delta`，`to → from` 权重 `-delta`。轴向和符号由工具根据真实实体及已声明的坐标方向确定，不从图中文字位置猜测。

例如，GT 要求孔的 X 坐标为 20，模型标出总长 50 与右距 30：

```text
left.x = 0                      固定基准
right.x - left.x = 50            总长
right.x - hole_1.center.x = 30    孔到右边

left.x → right.x → hole_1.center.x
0         50              20
```

这与直接标注 `hole_1.center.x - left.x = 20` 等价。

## 2 分图与可用信息

分别建立 X、Y、Z 关系图。直径、半径、深度、长度先用参数约束表处理；合法的半径与直径换算可作为明确规则。跨视图的坐标关系须经过工具确认的坐标变换，不能把不同局部方向直接放进同一图。

图中只加入图纸实际表达、附着有效且经工具确认的关系。固定基准用于去除任意整体平移；不能把 GT 中所有坐标或从输入 STEP 测得的全部尺寸预填成已知节点，否则漏标也会被错误判全。

“两孔 Y 坐标相同”只有在图纸上通过有效的对齐、对称或阵列表达提供了这一信息时，才能转换成差值为零的边。不能因为评分器知道它们等高，就替模型补上这条边。

## 3 BFS 或 DFS

对每个轴，从已固定的基准节点出发传播：

```text
value[datum] = 0
queue = [datum]

while queue 非空:
    u = 弹出一个节点
    for (v, delta, dimension_id) in adjacency[u]:
        candidate = value[u] + delta
        if v 尚未赋值:
            value[v] = candidate
            parent[v] = (u, dimension_id)
            将 v 入队
        else if candidate 与 value[v] 超出容差:
            记录矛盾环，标记该约束分量不一致
```

检查 `required_variables`：位置量是否能从对应基准到达，标量尺寸是否被确定，离散结构是否已表达。保存 `parent`，就能返回具体证明路径，例如 `d_length → d_right_offset`，而不是只输出一个分数。

未连接基准的节点属于位置欠约束，即使它们彼此连通也不完整。可对未锚定分量再做一次临时起点遍历来发现内部矛盾，但临时起点不能成为正式坐标证据。

对于方向已知的差值约束，锚定分量内的一致传播可以确定相应坐标。无方向欧氏距离、角度或一般非线性关系不适用这个结论，应转交专门规则或求解器；“图连通”本身不保证一般几何问题唯一可解。

## 4 带权并查集

若模型逐条添加标注，可维护带势能差的并查集：每个节点记录到父节点的数值差，合并时维持 `q[to] - q[from] = delta`。

- 两节点属于不同集合：加入关系并合并。
- 属于同一集合：比较已有势能差与新关系，可识别一致重复或矛盾。
- 节点与基准同集合：可查询其相对基准坐标。

路径压缩和按秩合并使每次操作的摊还复杂度为 O(α(V))。为了输出原始尺寸链证据，还需保留原始邻接图或证明森林；压缩后的父指针不等于实际标注路径。第一版采用 BFS 即可，并查集是增量优化选项。

## 5 冗余标注

整张图的有效标注统一展开为 Ax=b。没有“新增标注”的时间顺序。m−rank(A) 给出独立的行依赖数量；通过左零空间 yᵀA=0 返回参与依赖的标注集合。yᵀb=0 为一致依赖，非零为矛盾证据。一般 SVD 基底不是最小冲突集，不能将基底中某一项当成唯一错误责任项。

矩阵行记录原始 annotation_id；一个工程说明可以展开多条标量约束。效率现按独立行数/总行数计算，报告另行汇总标注集合。不是逐项删除，也不是遍历所有简单路径；同一个重复关系传播到后续参数时，不会因多条组合路径而反复扣分。参考尺寸豁免及语义组成本仍需正式规则校准。

当前直接调用 NumPy/LAPACK 的 SVD，按变量连通分量拆块；几百条关系的实测见 MATRIX_METHOD.md。更大稀疏系统可选 SuiteSparseQR，当前未接入。已移除逐项删除重算；图纸解析、碰撞检查和渲染耗时另计。

## 6 首轮输出与验收

输出每个必要变量的 `determined`、`missing` 或 `inconsistent` 状态，以及所用标注 ID；同时报告离散结构遗漏、冗余候选和不支持的约束类型。

[尺寸链示例](../examples/dimension_chain/README.md) 给出五个连续量的关系记录，以及等价、缺失、重复和矛盾四种手工预期行为。现在可用 `python tools/run_framework_demo.py` 实际验证这些行为。v0.1 采用线性消元实现该关系 IR，并增加双孔对称方程的验证；BFS 和带权并查集仍是差值约束的替代实现方案。详见 [框架说明](FRAMEWORK.md)。
