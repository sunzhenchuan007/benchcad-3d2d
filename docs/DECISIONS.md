# 已确认决定与待办

更新：2026-10-16。此页是简版；[设计](DESIGN.md)与[架构](ARCHITECTURE.md)解释细节。

| 问题 | 当前决定 |
|---|---|
| 一个还是两个仓库 | 同一个 benchcad-3d2d；SolidWorks 与 FreeCAD 两个 CAD 后端 |
| Agent 与 CAD 的关系 | Codex CLI 是接入方式，CAD 是可替换后端 |
| 输入 | 允许读取 STEP、编程计算几何并查看生成图纸；Case 13 额外使用中性原生缓存 |
| 评分 JSON 来源 | 控制程序读取 CAD 最终状态／受控日志派生，AI 不自写剖切评分答案 |
| 当前交卷 | SolidWorks 原生图纸＋提交标记，控制程序导出最终 DXF／PNG／JSON |
| 几何评测 | 独立 AI 只用最终 DXF 和其 PNG 重建 STEP，再与原 STEP 比较 |
| IoU | 各自居中并等比例归一化，24 个旋转＋镜像后 24 个旋转，取较高值 |
| 镜像显示 | 严格提高时显示两值并标记；较低或持平时仅显示原旋转值 |
| 专家 DXF 重建校正 | 暂缓；不生成专家基准 STEP，不计算除以专家 IoU 的比值 |
| 尺寸链评分 | 退出主路线；历史资料保留 |
| 过程记录 | 记录可见操作、反馈、失败、耗时和可取得的快照；不是完整内部思维链 |
| 批量案例 | 仓库仍注册 01/13/15/84/86/88；另已选择 Drive T1 01–10 作为后续批次，尚未导入或跑完 |

## 尚需实施或冻结

- SolidWorks 可移植控制器迁移；当前本地代码未随此次文档发布。
- FreeCAD 工具、导出、原生状态提取与端到端验收。
- 批准的剖切 GT、实际图纸证据匹配、完整碰撞与视图数评分。
- 所有工具访问路径的隔离验收；立即封卷接口。
- 正式重建模型／提示词／采样重试与聚合规则；正式统一预算。
- 是否增加模型决策轮硬上限；当前试验只实行时间预算等已有约束。
- 总分、容差与失败处理。专家重建校正为暂缓项，不是当前前置任务。
