# BenchCAD 三维到二维工程图评测方案

更新：2026-10-16。**同一个 benchmark，SolidWorks 与 FreeCAD 两个 CAD 后端。出图 AI 读取 STEP，通过 CAD 工具制作工程图；独立重建 AI 只读最终 DXF 和其预览，再输出 STEP 供评测器比较。**

本页为当前规则入口，替代早期尺寸链验证、AI 自写剖切评分 JSON 和专家重建分母校正的方案。完整总分尚未冻结；后端状态见 [STATUS.md](STATUS.md)。

## 1. 输入、观察和输出

出图 AI 可直接读取标准化 STEP，并用 Python 计算几何、调用 CAD、渲染和查看自己的二维图纸。当前 SolidWorks 试验没有默认六视图或独立的六视图查询服务。模型可在任务预算内多次生成预览；先渲染再调用看图工具，才得到图像反馈。

输入保留真实尺寸、单位和坐标，记录 SHA-256。评分阶段的归一化不改写输入。Case 13 另提供由同一 STEP 转换的中性原生缓存以绕过受限账户导入问题，实验条件必须写明，不能称为严格 STEP-only。

AI 负责视图、剖切、尺寸和布局。最终二维评测产物是 DXF；在 SolidWorks 已测流程中，AI 交原生 .SLDDRW 和提交标记，由控制程序重开、导出 DXF、提取 drawing.json 并渲染 PNG。JSON 不是出图 AI 自报答案。FreeCAD 计划用 .FCStd 接入同一职责边界，尚未实现验收。

原生来源设计树、专家图纸、GT 与评测结果不提供给出图 AI。原 STEP、任何原生三维模型、GT、出图日志和派生 JSON 都不提供给重建 AI。文件权限或沙箱必须实际落实这些规则；文件夹叫 private_gt 不构成保密。完整访问路径验收仍未完成。

## 2. 几何恢复：独立 AI 重建与 IoU

不使用尺寸链、约束矩阵或逐项删除标注作为当前图纸完整性验证。固定独立重建模型、提示词、工具和预算，让它从最终 DXF 与该 DXF 的 PNG 恢复三维实体。分数不反馈给本轮出图或重建模型。

IoU = Volume(R ∩ G) / Volume(R ∪ G)，其中 R 为重建几何，G 为参考几何。当前本地政策为 `normalized-iou48-mirror-max/1`：

1. 两模型各自按包围盒中心居中，按各自最长包围盒边等比例归一化。
2. 原候选搜索 24 个正交旋转，得到仅旋转最高值。
3. 候选关于 XY 平面镜像，再搜索 24 个正交旋转。
4. 采用两者较高值；镜像严格更高时报告两个值并标记 `reflection_used=true`；较低或持平时只报告原旋转值，标记 false。

`iou24` 保持仅旋转值，`iou` 是新规则采用值。48 个正交变换不包括任意连续角度配准。归一化消除了绝对大小和位置差异，并允许镜像等价；绝对尺寸比与镜像标记另行报告。该规则不是旧的保留绝对尺度方案。

Case 13 的仅旋转值为 0.4848302861，镜像值和采用值为 0.9996046703。原模型与自身旋转／平移副本的 1.0 是评测器自检，不是另一次 AI 成绩。镜像后仍有几何差异，不能把剩余误差全部解释为体素误差。

IoU 反映几何恢复，但不能单独证明标注规范或小孔、薄壁完整，也不能只凭一个低分把责任全部归给出图 AI。固定重建器减少变因，不消除重建器误差。

## 3. 专业剖切：比较要求与实际状态

专家 GT 定义哪些空间位置必须表达，CAD 派生 JSON 记录实际画了哪些剖视。两者做几何约束匹配，不按 JSON 字段完全相等或 DXF handle 同名匹配。

| 规则 | 条件 |
|---|---|
| contains_axis | 切面包含整条目标轴线；仅在一点相交不算 |
| crosses_axis_at_station | 切面与轴的唯一交点位于规定轴向位置与容差内 |
| 不要求角度 | 满足相应位置规则即可 |
| 要求角度 | 额外检查切面法向与参考法向的夹角；法向正反视作同一平面 |

沿轴剖检查方向平行及轴到面的偏移；横切检查唯一交点与轴向站位。观察方向、箭头方向和切除范围不能由单纯的法向正负等价替代。

必要项、可选项／推荐项和可替代组应与 GT 版本一起定义。缺少必要表达可扣分；可选项缺失不自动判错，推荐奖励尚未冻结。不同合法布局和等价表达不因未复制专家图纸而扣分。全剖加外形视图可在满足要求时替代半剖，不强制所有对称零件使用半剖。

派生 JSON 必须与最终 DXF 的剖视、切线、箭头和标识建立证据对应。原生状态提取和文件哈希不能单独证明图纸表达合格。单平面数据不能冒充完整半剖、阶梯剖或局部剖定义。

Case 13 已提取两个原生剖切位置，但缺批准 GT，专业度未评分。当前公共日志接口只支持普通投影和单平面全剖，复杂类型明确拒绝。

## 4. 标注碰撞与视图冗余

检查实际 DXF 中的文字、尺寸线、引出线、箭头与几何遮挡。包围盒相交只生成候选，正常附着和允许交汇不能直接扣分。Case 13 的 12 处候选不是 12 处已确认错误。

标注放在不同视图，只要信息等价且清楚，不因位置不同扣分。主要视图包括普通投影、全剖、半剖、阶梯剖；部分视图包括局部剖与局部放大。这是分类约定，不代表所有类型已有后端适配。

视图数评分须先满足完整性和必要剖切要求，再比较相应类别的专家参考数：不超过参考时该项不扣分，超过时按预先固定规则扣分。缺失必要视图不能靠少画获得满分；可替代方案的计数方式与扣分幅度仍待冻结。PDF 识别保留后续接口，暂不完善。

## 5. 暂缓与未解决事项

**暂不执行专家 DXF → AI 重建 STEP 的基准路线，不计算 AI 图纸重建 IoU ÷ 专家图纸重建 IoU。** 这不暂停 AI 所画图纸的独立重建，也不取消专家剖切 GT。
